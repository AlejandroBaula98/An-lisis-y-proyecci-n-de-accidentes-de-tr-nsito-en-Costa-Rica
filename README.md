# An-lisis-y-proyecci-n-de-accidentes-de-tr-nsito-en-Costa-Rica
Proyecto académico de análisis exploratorio de datos del COSEVI correspondientes a 2020–2022. Limpieza y transformación de datos con pandas, visualización con Matplotlib y Seaborn, y desarrollo de un modelo de proyección que combina Random Forest y regresión lineal, con evaluación mediante RMSE y R².
